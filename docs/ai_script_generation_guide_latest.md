# AI向け 近道君 台本生成ガイド 最新版

作成日: 2026-06-08  
対象: `short-videoGPT / 近道君`

この資料は、AIに近道君用の台本を生成させるための指示書です。AIはこの形式だけを守り、動画生成UIの「台本」欄へそのまま貼り付けられる本文を出力してください。

## 最重要ルール

- 最終出力は台本本文だけにする。
- Markdown見出し、解説、注釈、制作メモ、箇条書きを台本の外に出さない。
- 1つの空行で1シーンを区切る。
- 各シーンは原則 `映像：` から始める。
- 発話は `話者名：セリフ` で書く。
- 字幕は短くする。発話全文をそのまま字幕にしない。
- `字幕：` と `テキスト：` に同じ長文を重複させない。
- 数字、制度、因果関係、比較はできるだけ `[graphic:*]` で表現する。
- 少佐または分析官Kの直接解説シーンは口パク対象として使える。

## 基本フォーマット

```text
映像：[graphic:title] タイトル文字
GMN：導入のセリフ。
字幕：短い導入字幕。

映像：[graphic:flow] 原因 → 仕組み → 結果
GPT：構造を説明するセリフ。
字幕：原因から結果までを見る。

映像：[motoko:fullscreen]
少佐：ここからは、私が直接説明します。
字幕：少佐が直接説明する。
```

## 話者

使用できる主な話者:

| 話者 | 用途 |
| --- | --- |
| `GMN` | 司会、導入、視聴者目線の問い |
| `GPT` | 論理整理、制度説明 |
| `YT` | 数値、資料、データ説明 |
| `META` | メタ視点、情報構造の説明 |
| `Grock` / `GROCK` | 強い突っ込み、対立軸 |
| `CLAUDE` / `クロード` | 慎重な補足、レビュー |
| `AnalystK` / `分析官K` | 分析官Kの専用音声と口パク対象 |
| `少佐` / `Major` | 少佐のStyleBertVITS2音声と口パク対象 |

推奨:

- 分析官Kを使う場合は `AnalystK：` を基本にする。
- 少佐を使う場合は `少佐：` を基本にする。
- `少佐：` は口パク動画または静止画表示の対象になる。
- `AnalystK：` と `少佐：` は、UIの「分析官K／少佐 口パク設定」に従って表示される。

## 映像タグ

### ローカル合成タグ

制度説明、数値比較、図解は外部動画生成よりローカル合成を優先してください。

| タグ | 用途 |
| --- | --- |
| `[graphic:title]` | タイトル、章区切り、結論 |
| `[graphic:meeting_room]` | 会議室、複数話者の討論 |
| `[graphic:talker_GMN]` | GMNを強調 |
| `[graphic:talker_GPT]` | GPTを強調 |
| `[graphic:talker_YT]` | YTを強調 |
| `[graphic:talker_AnalystK]` | 分析官Kを強調 |
| `[graphic:talker_Major]` | 少佐を強調 |
| `[graphic:talkers_GMN+YT]` | 複数話者を同時強調 |
| `[graphic:dark_text]` | 暗色背景の強調文字 |
| `[graphic:light_text]` | 明色背景の説明文字 |
| `[graphic:bar_chart]` | 棒グラフ、数値比較 |
| `[graphic:flow]` | 制度の流れ、因果関係 |
| `[graphic:sepia]` | 過去資料、歴史、古い制度 |

例:

```text
映像：[graphic:bar_chart] 令和4年度:27784 令和5年度:42072
YT：件数は、1年で大きく増えています。
字幕：件数は1年で大きく増えた。
```

```text
映像：[graphic:flow] 売上 → 仕入 → 控除 → 還付
GPT：流れにすると、制度の構造が見えてきます。
字幕：流れで制度の構造を見る。
```

### 通常映像プロンプト

実写風や情景描写が必要な時だけ自然文で書きます。

```text
映像：雨の夜の地方商店街。閉まったシャッター、濡れた道路、ドキュメンタリー風。
GMN：静かな街にも、制度の圧力は届いています。
字幕：制度の圧力は、静かな街にも届く。
```

注意:

- 通常映像は生成失敗や待ち時間が出やすい。
- 税制、数字、資料、因果関係は `[graphic:*]` を使う。

## 少佐・分析官Kの口パク指定

UIで口パク設定を選ぶと、`AnalystK：` または `少佐：` の発話シーンに口パク動画または静止画が使われます。

シーン単位で強制したい場合は、`映像：` 行に `[motoko:*]` を入れます。

| 指定 | 動作 |
| --- | --- |
| `[motoko:fullscreen]` | 口パク画面をシーン全体に表示 |
| `[motoko:bottom]` | 元シーンの下側に口パクを重ねる |
| `[motoko:explain_right]` | 標準横長で右側に話者、左側に字幕 |
| `[motoko:anime]` | アニメセットを使う |
| `[motoko:real]` | リアルセットを使う |

例:

```text
映像：[motoko:fullscreen]
少佐：給付付き税額控除という言葉は、優しく聞こえます。しかし設計図を見ると、負担の移し替えが見えてきます。
字幕：優しい言葉の裏に、負担の移し替えがある。
```

```text
映像：[motoko:explain_right] [motoko:anime]
AnalystK：ここでは、制度の名前ではなく、お金の流れを見ます。
字幕：名前ではなく、お金の流れを見る。
```

## 口パク画面へのグラフ重ね合わせ

少佐または分析官Kの全画面口パクに、グラフやテキストを重ねたい場合:

```text
映像：[motoko:fullscreen] [overlay:graphic:*] [graphic:bar_chart] 国内企業:重い 輸出大企業:軽い
少佐：国内には重く、輸出には軽い。ここに、制度の非対称性があります。
字幕：国内には重く、輸出には軽い。
```

ルール:

- `[overlay:graphic:*]` は、同じ行の `[graphic:*]` を前面に重ねる指定。
- 口パク主体のシーンでは、字幕を短くする。
- グラフ情報を詰め込みすぎない。項目は2から4個程度にする。

## 標準長尺の解説動画スタイル

標準横長動画では、少佐または分析官Kを右側に表示し、字幕を左側へ置く解説動画スタイルが使えます。

```text
映像：[motoko:explain_right] [graphic:flow] 税額控除 → 給付 → 恒久財源 → 消費税
少佐：この流れを見ると、給付の話が、いつの間にか恒久財源の話へ変わっていることがわかります。
字幕：給付の話が、恒久財源の話へ変わる。
```

長尺の作り方:

- 1シーン1論点にする。
- 長いセリフは句読点で区切り、複数シーンへ分ける。
- 少佐の長ゼリフは80から140文字程度を目安にする。
- 字幕は1文、最大2行程度にする。
- 右側解説では、左側字幕が読めるように `テキスト：` を乱用しない。

## 字幕とテキスト

### 字幕

字幕は視聴者の理解を固定する短文です。

```text
字幕：名前ではなく、構造を見る。
```

字幕の指針:

- 12から28文字程度を基本にする。
- 長いセリフでも字幕は短く要約する。
- 字幕がない場合、発話から自動生成される場合がある。
- 字幕を出したくない作品ではUI側で字幕を無効化する。

### テキスト

`テキスト：` は画面上に固定表示する短い強調文です。

```text
テキスト：名前は還付、効果は補助金
```

禁止:

- `字幕：` と同じ文章を `テキスト：` に入れない。
- 長文を入れない。
- グラフや口パク画面の上に長いテキストを重ねない。

## BGMと素材挿入

### BGM

```text
映像：[graphic:title] 消費税の闇 [bgm:serious_doc]
GMN：ここから、設計図を見ていきます。
字幕：設計図を見る。
```

BGMを止める:

```text
映像：[graphic:dark_text] 結論 [bgm:off]
少佐：この一点だけ、覚えてください。
字幕：この一点だけ、覚えてください。
```

### insert

既存素材を重ねる場合:

```text
映像：[graphic:meeting_room] [insert:graph_30k_over]
YT：資料を見ると、増加の幅がわかります。
字幕：資料で増加の幅を見る。
```

警告表示:

```text
映像：[graphic:dark_text] 督促の連鎖 [insert:notice:warning]
GPT：これは単なる通知ではなく、資金繰りを削る圧力です。
字幕：通知が、資金繰りを削る。
```

## ショート動画の構成

57秒ショートの推奨構成:

1. タイトルと違和感
2. 制度の仕組み
3. 数字または資料
4. 視聴者に刺さる転換
5. 少佐または分析官Kの締め

テンプレート:

```text
映像：[graphic:title] {強いタイトル}
GMN：{違和感を提示する短い導入}
字幕：{一瞬でわかる導入}

映像：[graphic:flow] {制度A} → {制度B} → {結果}
GPT：{流れを説明する}
字幕：{流れの要約}

映像：[graphic:bar_chart] {項目1}:値 {項目2}:値
YT：{数字の意味を説明する}
字幕：{数字の意味}

映像：[graphic:dark_text] {矛盾を示す短文}
GMN：{視聴者の感情に接続する}
字幕：{矛盾の一文}

映像：[motoko:fullscreen]
少佐：{冷静で強い締め。長すぎない}
字幕：{締めの短文}
```

## 標準長尺の構成

標準長尺は、章立てで視聴者の理解を積み上げます。

推奨:

- 冒頭で結論を先に出す。
- 1章ごとに `graphic:title` を入れる。
- 数字は `bar_chart`、制度は `flow`、問いは `meeting_room` を使う。
- 少佐または分析官Kは、章末の整理役として使う。
- 右側解説スタイルは、長い制度説明に向く。

テンプレート:

```text
映像：[graphic:title] {長尺タイトル}
GMN：{今回の結論を先に提示する}
字幕：{結論の短文}

映像：[graphic:flow] {起点} → {政策名} → {財源} → {負担}
GPT：{制度の流れを説明する}
字幕：{制度の流れを見る}

映像：[motoko:explain_right] [overlay:graphic:*] [graphic:bar_chart] {項目1}:値 {項目2}:値
少佐：{数字の意味を、冷静に解説する}
字幕：{数字が示す構造}

映像：[graphic:title] {章タイトル}
GMN：{次の章へ接続する}
字幕：{次の論点}
```

## 読み上げ品質のための書き方

TTSへ渡す前に辞書変換と数字読み変換が入ります。以下の語は辞書登録済みです。

```text
近道君、少佐、分析官K、消費税、法人税、社会保障、給付付き税額控除、税額控除、所得控除、
人頭税、輸出還付、雇用保護、借入、人件費、外注費、外食、外される、控除、重複督促、俯瞰、
社保、蝕む、鏡の国、設計図、医療崩壊、一次ソース
```

AIが注意すること:

- 難読語はむやみに増やさない。
- アルファベット略語は必要最小限にする。
- 数字は表示用なら数字でよいが、発話は自然に読める文にする。
- 長い固有名詞は、1シーン内で何度も繰り返さない。

## 失敗しやすい書き方

悪い例:

```text
映像：[graphic:dark_text] とても長い文章を画面いっぱいに表示して、さらに字幕にも同じ文章を入れて、少佐にも同じ内容を長く話させる
少佐：とても長い文章を画面いっぱいに表示して、さらに字幕にも同じ文章を入れて、少佐にも同じ内容を長く話させると、視聴者が追いつかなくなります。
字幕：とても長い文章を画面いっぱいに表示して、さらに字幕にも同じ文章を入れて、少佐にも同じ内容を長く話させる
```

良い例:

```text
映像：[graphic:dark_text] 情報量を絞る
少佐：画面に出す言葉と、耳で聞かせる言葉は、役割を分けます。
字幕：画面と言葉の役割を分ける。
```

## AIへの生成指示テンプレート

AIに台本作成を依頼する時は、次の指示を添えると安定します。

```text
あなたは近道君の台本生成AIです。
以下のルールを守って、動画生成UIへそのまま貼り付けられる台本本文だけを出力してください。

- シーンは空行で区切る
- 各シーンは映像：から始める
- 発話は 話者名：セリフ 形式
- 字幕は短く要約する
- 数字、制度、比較、流れは [graphic:bar_chart] または [graphic:flow] を使う
- 少佐の直接解説は 映像：[motoko:fullscreen] または [motoko:explain_right] を使う
- 字幕：とテキスト：に同じ文章を重複させない
- 台本以外の説明文を出力しない

テーマ:
{ここにテーマを書く}

尺:
{ショート57秒 / 標準長尺10分以上など}

トーン:
{硬質ドキュメンタリー / 冷静な制度解説 / 強い問題提起など}
```

## 完成例

```text
映像：[graphic:title] 給付付き税額控除という名の増税
GMN：優しい言葉ほど、設計図を見なければいけません。
字幕：優しい言葉ほど、設計図を見る。

映像：[graphic:flow] 所得控除 → 税額控除 → 給付 → 恒久財源
GPT：制度の名前は支援に見えます。しかし流れを追うと、最後に財源の話へ接続します。
字幕：支援の話が、財源の話へ変わる。

映像：[graphic:bar_chart] 給付:増 恒久財源:必要 消費税:候補
YT：給付を恒久化するなら、恒久財源が必要になる。ここで消費税が顔を出します。
字幕：恒久化には、恒久財源が必要になる。

映像：[motoko:fullscreen] [overlay:graphic:*] [graphic:dark_text] 名前は支援、構造は負担
少佐：名前は支援です。しかし構造は、負担の置き換えです。ここを見誤ると、制度の本質を外します。
字幕：名前は支援。構造は負担。

映像：[graphic:title] 次に見るべきもの
GMN：次は、誰が負担し、誰が軽くなるのかを見ます。
字幕：次は、負担の移動を見る。
```
