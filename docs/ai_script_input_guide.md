# AI向け 近道君 台本入力ガイド

このファイルは、AIに `short-videoGPT / 近道君` 用の台本を書かせるための入力仕様です。AIは、ここに書かれた形式だけを守って台本を出力してください。

## 目的

台本は、動画生成UIの「台本」欄へそのまま貼り付けるテキストです。  
1つの空行で区切られた1ブロックが、基本的に1シーンになります。

AIは説明文やMarkdown見出しを混ぜず、最終出力は台本本文だけにしてください。

## 基本構造

```text
映像：[graphic:meeting_room]
GMN：今日の論点を整理します。
字幕：今日の論点を整理する。

映像：[graphic:talker_AnalystK]
AnalystK：ここからは、数字の裏側を見ます。
字幕：数字の裏側を見る。
```

基本ルール:

- シーン同士は空行で区切る。
- 各シーンの先頭付近に `映像：` を置く。
- 発話は `話者名：セリフ` の形式で書く。
- `字幕：` は任意。省略すると発話から自動生成される。
- `テキスト：` は画面上に固定表示したい文字だけに使う。
- 台本以外の説明、箇条書きの解説、制作メモは出力しない。

## 使用できる話者

推奨話者名:

```text
GMN
AnalystK
YT
META
GPT
Grock
CLAUDE
```

日本語名を使う場合:

```text
分析官K
調査員S
クロード
```

安定運用では `AnalystK` を推奨します。分析官Kの専用音声、口パク動画、リアルセット/アニメセットの連携対象になります。

## 映像指定

### ローカル合成のgraphicタグ

制度説明、グラフ、会議画面、強調テキストは `[graphic:*]` を使います。これは外部動画生成を使わず、ローカルで安定生成されます。

```text
映像：[graphic:meeting_room]
```

主なタグ:

| タグ | 用途 |
|---|---|
| `[graphic:meeting_room]` | 会議室・討論画面 |
| `[graphic:talker_GMN]` | GMNを強調 |
| `[graphic:talker_AnalystK]` | 分析官Kを強調 |
| `[graphic:talker_YT]` | YTを強調 |
| `[graphic:talker_META]` | METAを強調 |
| `[graphic:talker_GPT]` | GPTを強調 |
| `[graphic:talker_GROCK]` | Grockを強調 |
| `[graphic:talkers_GMN+YT]` | 複数話者を同時強調 |
| `[graphic:title]` | タイトル画面 |
| `[graphic:dark_text]` | 暗色背景の強調テキスト |
| `[graphic:light_text]` | 明色背景の説明テキスト |
| `[graphic:bar_chart]` | 棒グラフ、数値比較 |
| `[graphic:flow]` | 因果関係、制度の流れ |
| `[graphic:sepia]` | 古い資料、過去、歴史風 |

例:

```text
映像：[graphic:bar_chart] 令和4年度:27784 令和5年度:42072
YT：件数は、1年で大きく増えています。
字幕：件数は、1年で大きく増えている。
```

```text
映像：[graphic:flow] 売上 → 仕入 → 差額 → 還付
GPT：流れで見ると、制度の構造がはっきりします。
字幕：流れで見ると、制度の構造が見える。
```

### 通常の映像プロンプト

実写風・ドキュメンタリー風の自然映像を作りたい場合は、`[graphic:*]` を使わず、映像内容を自然文で書きます。

```text
映像：雨の夜の地方商店街。閉まったシャッター、濡れた道路、ドキュメンタリー風。
GMN：静かな街にも、制度の圧力は届いています。
```

注意:

- 外部動画生成モードを使うため、待ち時間や失敗の可能性があります。
- 数字、図解、制度説明は `[graphic:*]` を優先してください。

## 分析官Kの口パク指定

分析官Kだけを口パク動画として表示したい場合は、通常はUI側の「分析官K 表示方法」で選択します。

台本内で、そのシーンだけ強制的に全画面口パクにしたい場合:

```text
映像：[motoko:fullscreen]
AnalystK：ここは、私が直接説明します。
字幕：ここは、分析官Kが直接説明する。
```

### 口パク全画面にグラフやテキストを重ねる

少佐/分析官Kの口パク画面をベースにして、その上にグラフやテキストを重ねたい場合:

```text
映像：[motoko:fullscreen] [overlay:graphic:*] [graphic:bar_chart] 売上:100 税負担:38
AnalystK：見てください。利益ではなく、先に税負担が立ち上がっています。
字幕：利益ではなく、先に税負担が立ち上がる。
```

ルール:

- `[motoko:fullscreen]` はそのシーンだけ分析官Kを全画面口パクにする。
- `[overlay:graphic:*]` は同じ行の `[graphic:*]` を前面オーバーレイにする。
- 背景のぼかし顔表示は使わず、現在は黒寄り背景に収める方式。

## 字幕とテキスト表示

### 字幕

字幕は画面下部に出る読み用テキストです。

```text
字幕：ここで、数字の意味が変わります。
```

字幕を省略すると、発話から自動生成されます。明確に短く見せたい時だけ `字幕：` を使ってください。

### テキスト

`テキスト：` は画面上に固定表示する強調文です。字幕とは別物です。

```text
テキスト：赤字でも納税義務
```

注意:

- 長い文章を `テキスト：` に入れない。
- 字幕と同じ内容を `テキスト：` に重複させない。
- 画面が読みにくくなるため、1行から2行程度にする。

## insertタグ

既存の画像・動画・URL素材をシーンに重ねる場合に使います。

```text
映像：[graphic:meeting_room] [insert:graph_30k_over]
YT：この資料を見ると、増加の幅がわかります。
```

強い警告演出として中央に出したい場合:

```text
映像：[graphic:meeting_room] [insert:news_starvation:warning]
GPT：これは単なる手続きの遅れではありません。
字幕：これは単なる手続きの遅れではない。
```

対応素材の置き場所:

```text
storage/assets/inserts/
storage/inserts/
```

## BGM指定

シーンごとにBGMを指定できます。

```text
映像：[graphic:title] 消費税の正体 [bgm:serious_doc]
GMN：ここから、本題に入ります。
```

BGMを切りたい場合:

```text
映像：[graphic:dark_text] 無音で見せる結論 [bgm:off]
AnalystK：この数字だけを見てください。
```

## シーン分割の考え方

1シーンに入れる発話は短めにしてください。長すぎる発話は、音声・字幕・映像尺が崩れやすくなります。

推奨:

- 1シーン1話者を基本にする。
- 1発話は80文字から160文字程度まで。
- 長い説明は複数シーンに分ける。
- 数字を見せる場面では `[graphic:bar_chart]` や `[graphic:flow]` を使う。

悪い例:

```text
映像：[graphic:meeting_room]
GMN：非常に長い説明を一気に話し続け、字幕も長くなり、画面上の情報も多くなり、視聴者が追いつけなくなるような文章を1シーンに全部入れてしまう。
```

良い例:

```text
映像：[graphic:meeting_room]
GMN：まず、構造だけを見ます。問題は、税率そのものではありません。
字幕：問題は、税率そのものではない。

映像：[graphic:flow] 売上 → 納税 → 資金不足
YT：流れにすると、資金がどこで止まるのかが見えてきます。
字幕：資金がどこで止まるのかを見る。
```

## AIが守るべき禁止事項

- 台本の前後に説明文を付けない。
- Markdown見出し `#` や箇条書きで解説しない。
- `字幕：` と `テキスト：` に同じ長文を重複させない。
- 1シーンに複数の長い発話を詰め込まない。
- グラフに向いた内容を自然映像プロンプトだけで処理しない。
- 架空の資料番号や未確認の事実を断定しない。

## AI出力テンプレート

AIは以下の形で出力してください。

```text
映像：[graphic:title] タイトル
GMN：導入のセリフ。
字幕：短い字幕。

映像：[graphic:meeting_room]
AnalystK：論点を整理するセリフ。
字幕：論点を整理する。

映像：[graphic:bar_chart] 項目A:10 項目B:25
YT：数字を説明するセリフ。
字幕：数字の差を見る。

映像：[graphic:flow] 原因 → 結果 → 結論
GPT：構造を説明するセリフ。
字幕：原因から結論までを見る。

映像：[graphic:dark_text] 結論
GMN：締めのセリフ。
字幕：結論を短く示す。
```
