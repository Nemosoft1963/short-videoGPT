# 近道君 台本作成AIマニュアル

このマニュアルは、別のAIが近道君へそのまま入力できる台本を作るための現行仕様です。台本はシーンごとに映像、音声、字幕を指定します。特に、登録静止画から動画を作る場合は、静止画の登録と台本内の開始フレーム指定を分けて扱ってください。本書は台本入力欄向けの記法を説明し、シリーズ一括取り込み用Markdownの見出し形式は対象にしません。

## AIの出力契約

依頼者から台本作成を頼まれたAIは、次の規則を守ります。

1. 最終出力は台本本文だけにし、前置き、制作メモ、Markdown見出し、コードフェンスを付けない。依頼者が解説も求めた場合だけ、台本とは明確に分ける。
2. 1シーンを1ブロックとし、ブロック間に空行を1行入れる。各ブロックは原則 `映像：` から始める。
3. 発話は `話者名：セリフ` または `ナレーション：セリフ`、字幕は `字幕：短い要約` と書く。
4. 映像方式はシーンごとに一つを選ぶ。登録動画、登録静止画からの生成、ローカル図解、通常映像を混在させない。
5. 素材のファイル名と一次資料の事実・数字を創作しない。不明なら依頼者に確認し、未登録素材のタグを勝手に書かない。
6. 指定尺を無音や同じ文の反復だけで埋めない。1シーン1論点で、発話量と情報量をそろえる。

最小の台本例:

```text
映像：[graphic:title] 動画の題名
GMN：まず、今日の問いを一つ示します。
字幕：今日の問い。

映像：[graphic:flow] 原因 → 変化 → 結果
GPT：原因から結果まで、順番に確認します。
字幕：原因から結果を確認する。
```

## 入力の単位とラベル

`映像：`、`ナレーション：`、`字幕：`、`テキスト：` が基本ラベルです。`テキスト：` は映像内の固定表示用で、読み上げには使いません。各ラベルは半角コロンも認識しますが、日本語台本では全角コロンを推奨します。英語別名 `visual:`、`narration:`、`subtitle:`、`overlay:` もあります。

同じブロックに複数の話者を書くと、通常は話者ごとのシーンに展開されます。1つの映像を厳密に共有したい場合は1ブロック1話者を推奨します。複数話者を同画面にまとめる必要がある場合は `[graphic:talkers_GMN+YT]` などを使います。

話者は `GMN`、`GPT`、`YT`、`META`、`GROCK`、`CLAUDE`、`分析官K`、`DXおじさん`、`少佐`、`中佐`、`ナレーション` など、登録済みの名前を使います。`少佐` と `中佐` は別の音声です。`DXおじさん` は専用の男性音声設定です。`少佐` や従来の `分析官K` の口パク表示は別途設定・素材に依存し、`中佐：` と書くだけで口パク映像ができるわけではありません。

## 映像方式の選び方

| 台本の映像指定 | 生成時の扱い | 費用と前提 |
| --- | --- | --- |
| `映像：[graphic:flow] ...` | ローカルで図解・文字映像を合成 | 外部動画APIを使わない |
| `映像：自然文の情景描写` | 画面で選んだ動画生成モードへ渡す | 外部モードなら課金・待機があり得る。MOCは確認用映像 |
| `映像：[start_frame:画像.jpg] 動きの指示` | 登録画像を開始フレームにし、MiniMaxで動画生成 | 画面のモードに関係なく外部有料生成。画像登録が必要 |
| `映像：[clip:動画.mp4]` | 登録済みMP4をシーン全体で使用 | 再生成費用なし。動画登録が必要 |
| `[insert:素材名]` | 選んだ主映像の上に素材を重ねる | 主映像の代替ではない |

主映像を一つだけ指定してください。特に `[start_frame:...]` と `[clip:...]` を同じシーンに併記するとエラーになります。`[graphic:*]` と開始フレーム・登録動画の併記も避けてください。

### ローカル図解

主なタグは `[graphic:title]`、`[graphic:dark_text]`、`[graphic:light_text]`、`[graphic:bar_chart]`、`[graphic:flow]`、`[graphic:sepia]`、`[graphic:meeting_room]`、`[graphic:talker_GMN]`、`[graphic:talkers_GMN+YT]` です。タグの後に画面へ表示したい短い内容を書きます。未知の `graphic` 名は期待した専用画面にならないため、新しいタグ名を創作しないでください。

```text
映像：[graphic:bar_chart] 現在:100 変更後:85
YT：変更後は、現在より小さくなります。
字幕：変更後は小さくなる。
```

数値や制度の流れは、外部動画AIに正確な文字を描かせるのではなく、図解タグと短い画面テキストで示します。

### 通常の動画生成

`[graphic:*]`、`[clip:*]`、`[start_frame:*]` を使わない `映像：` の自然文は、画面で選択した動画生成モードの対象です。台本タグだけでRunwayやVeoなどのサービスをシーン単位に切り替える機能はありません。被写体、場所、動作、構図、カメラ、雰囲気を具体的に書き、映像内に正確な文字を生成させる指示は避けます。

### 登録静止画を開始フレームにする

先に画面の「開始フレーム用の静止画」からJPG・PNG・WEBP画像を登録します。台本では一覧に表示される**実在のファイル名**をそのまま使います。同名画像は重複登録できません。

```text
映像：[start_frame:ターニャのリアル静止画.jpg] 講義室で自然に瞬きし、手振りを交えて説明する。カメラは固定。
中佐：ここから、今日の論点を順番に説明します。
字幕：今日の論点を確認する。
```

`[image:ファイル名]` も同じ意味です。タグの後の動き・場面の指示は必須で、空なら生成を止めます。指示文はそのシーンの映像プロンプトとして使われ、字幕と音声は別工程で重ねられます。静止画を登録しただけでは外部生成は始まりません。通常の「生成開始」を押すと、そのタグを含むシーンだけMiniMaxの画像→動画生成を使います。完成したシーンのMP4はファイル名付きで動画素材一覧に入り、生成条件が一致する再利用にはキャッシュが使われます。

DXおじさん（分析官K）を登場させる場合は、現在の登録画像 `DXおじさん3.jpg` を開始フレームに指定します。中佐と同様、生成した動作映像にその場面の本人の音声を合わせて口パク処理します。他の話者が同じ場面で話す場合は、話者ごとに場面を分けてください。旧画像 `DXおじさん.jpg` と `DXおじさん2.jpg` は過去の台本用に残しています。

```text
映像：[start_frame:DXおじさん3.jpg] 教室の机でタブレットのグラフを示し、視聴者を見て自然にうなずく。カメラは固定。
DXおじさん：この数字が何を示しているか、一緒に確かめましょう。
字幕：数字の意味を確かめる。
```

この画像を指定した場面に限り、台詞を `分析官K：` と書いてもDXおじさんとして扱います。従来の `分析官K` の場面や音声は変更しません。DXおじさんの声は中高年の低めで柔らかい男性声を基調に、音程を下げつつ話速を保ち、語尾を曖昧にせず、意思を強く明晰に伝える設定です。人物像は「かつて古代ギリシャの王に進言した神官」。台詞は、威圧や大げさな芝居ではなく、落ち着いた洞察と静かな確信を感じさせる言葉を選びます。専用の声素材があれば後から差し替えられます。動画生成にはMiniMaxの利用料金が発生します。

開始フレームで作った映像を画面に見せたい場合、同じシーンに `[motoko:fullscreen]` を付けないでください。口パク映像が全画面を置き換えることがあります。短い外部生成クリップはシーン尺に合わせて繰り返される場合があります。長い発話なら論点ごとにシーンを分けます。

同じブロックに複数話者を書くと、話者ごとのシーンに展開され、それぞれが有料生成対象になり得ます。開始フレームを使うブロックは原則1話者にしてください。画像名が未登録なら生成前の確認で失敗します。

### 登録済みMP4を使う

既存MP4は画面から登録します。台本には素材一覧に表示される**実在のファイル名**を書きます。

```text
映像：[clip:ターニャの講義動画S.mp4]
中佐：この資料で、重要な点を確認します。
字幕：資料の重要点を確認する。
```

`[clip:ファイル名.mp4]` はシーン全体の映像として使われ、動画生成サービスへ再依頼しません。動画の元音声は最終シーンには引き継がれず、台本の音声・字幕が合成されます。旧式の素材ID指定も使えますが、新規台本ではファイル名を使ってください。

## 口パクと人物表示

少佐・分析官Kの発話シーンでは、登録された口パク素材と画面設定を利用できます。台本で表示を明示する場合、`[motoko:fullscreen]`、`[motoko:bottom]`、横長向けの `[motoko:explain_right]` を使います。素材セットは `[motoko:real]` または `[motoko:anime]`、素材形式は `[motoko:video]`、`[motoko:image]`、`[motoko:auto]` で指定できます。ただし、画面で「アニメセット」または「リアルセット」を選んだ場合は、その選択が台本内の素材セットタグより優先されます。素材が未設定なら、タグだけでは期待した口パクを保証できません。

```text
映像：[motoko:fullscreen] [motoko:video] [motoko:real]
少佐：結論を、ここで整理します。
字幕：結論を整理する。
```

`[motoko:anime]` と `[motoko:real]` を同一シーンで混ぜません。少佐の決め台詞など、シリーズ固有の文言は依頼者の指定がある場合だけ正確に入れてください。

## 補助指定

| 指定 | 用途 | 注意 |
| --- | --- | --- |
| `字幕：...` | シーンの字幕 | 省略時にセリフから自動生成されない。表示したいシーンには明記する |
| `テキスト：...` | 画面内の固定文字 | 発話や字幕と長文を重複させない |
| `[bgm:登録名]` | シーンのBGM | 実在するBGMだけを使う。画面側のBGM設定も確認する |
| `[bgm:off]` | シーンのBGM指定を空にする | これだけで画面側の全体BGMを必ず止めるわけではない |
| `[insert:素材名]` | 画像・動画を主映像に重ねる | 主映像ではない。素材名を創作しない |
| `[insert:素材名:warning]` | 警告表示として重ねる | 強い演出なので必要な場面だけ使う |
| `[overlay:graphic:*]` | 口パク画面上に図解を重ねる | 主に口パク全画面と組み合わせる |
| `[flash:red_impact]` | 短い警告フラッシュ | 多用しない。通常シーンと分ける |

字幕はシーン末尾まで表示する処理があり、表示位置・折り返し・タイプライター効果は画面の設定に従います。発話なしのカードでは `テキスト：` や `graphic` の内容を短くしてください。

## 台本ではなく画面で設定する項目

動画全体の縦型・横型、通常映像の生成サービス、字幕の表示位置と折り返し、ロゴ画像、全体BGM、音声エンジンなどは画面の設定です。台本作成AIは、存在しない専用タグを作ってこれらを変更しようとせず、依頼文の制作条件として受け取ってください。例外は台本タグが明示されたシーンで、`[start_frame:...]` はMiniMaxの画像→動画生成を指定し、`[graphic:*]` はローカル図解、`[clip:...]` は登録動画の再利用を指定します。

## 尺と話数

ショートは画面で44秒固定、57秒固定、台本に合わせる方式を選べます。横長には指定尺以上または台本尺を優先する方式があります。台本内に秒数を書いても、その値だけでシーン尺が固定されるわけではありません。セリフ量、字幕量、画面側の尺設定によって調整されます。

台本尺優先なら、発話が短いシーンは短くなります。固定尺では、発話量が少ないと映像が間延びします。短いシーンを機械的に引き伸ばさず、根拠、具体例、視聴者への影響を加えて内容を満たしてください。ショートの台本は長すぎるとシーン数の上限により後半が採用されない場合があるため、完成後にシーン一覧と尺を確認します。

複数話を作る場合は、**各話の台本を別々に出力**するのが安全です。一括取り込み用Markdownを作る場合は、依頼者が指定したシリーズ名・話数・見出し形式に従います。その見出しを動画生成画面の台本欄へそのまま貼らないでください。

## AIへ渡す依頼文

次の項目を埋め、このマニュアルと一緒に台本作成AIへ渡してください。波括弧は出力台本に残しません。

```text
近道君用の台本を作成してください。このマニュアルの「AIの出力契約」を守り、最終回答は台本本文だけにしてください。

テーマ：{テーマ}
目的：{視聴者に理解または行動してほしいこと}
形式と目標尺：{44秒ショート／57秒ショート／台本尺ショート／横長長尺}
話者：{使用する登録済み話者}
映像方式：{graphic中心／通常生成／登録静止画から生成／登録動画の再利用}
登録済み静止画：{実在するファイル名。不使用なら「なし」}
登録済み動画：{実在するファイル名。不使用なら「なし」}
確認済み事実と出典：{具体的な資料・数値。不明なら未確認と書く}
トーン：{例：冷静な解説}
必須文言：{指定があれば一字一句記す}

各シーンを空行で区切り、映像、発話、字幕を記述してください。未登録素材名・未確認数値は創作しないでください。
```

## 出力前の確認

- すべてのシーンに主映像を一つだけ指定したか。
- 話者名は登録済みで、セリフは自然な読み上げ文か。
- 字幕を表示したいシーンには `字幕：` があるか。
- `[start_frame:...]` のファイル名は登録済みで、動き・場面の指示が空でないか。
- `[clip:...]` と `[insert:...]` の素材名は実在するか。
- 開始フレームと登録動画を同一シーンで併記していないか。
- 口パクで使う人物・素材セット・画面の指定は矛盾しないか。
- 外部有料生成になるシーンを意図して指定しているか。
- 数字、制度、出典、シリーズ固有の決め台詞を創作していないか。
