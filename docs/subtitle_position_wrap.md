# 字幕の折り返し・表示位置設定

v0.7では、字幕が画面からはみ出ないように、以下を追加しました。

## 追加項目

- 字幕位置：下から何%上げるか
- 1行の文字数
- 同時表示する最大行数

## 推奨設定

```text
字幕サイズ: 72
字幕位置: 下から33%
1行の文字数: 14
最大行数: 3
```

字幕サイズを84以上にする場合は、1行の文字数を12〜14にしてください。

## 仕組み

1. 日本語の句読点、助詞、文節に近い位置で自動改行します。
2. 1ブロックが最大行数を超える場合、同じシーン内で字幕を分割表示します。
3. ASS字幕の `MarginV` を使い、画面下から指定%の位置に表示します。

## 注意

映像生成AIには日本語文字を描かせません。
日本語字幕はFFmpegで後処理として焼き込みます。
