# REMIX-05「銀行が貸さない理由」信用創造版
## 修正意図
「銀行が信用情報で確認」「公式資料に明記」を削除。  
公式に言えるのは、日本年金機構が督促後に滞納処分へ進む手順を示していること。  
銀行融資への影響は「資金繰り・納税状況・口座状況・差押えリスクとして審査に悪影響となり得る」に安全化。

```
映像：[graphic:title] 土地2,500万円でも銀行が貸さない [bgm:tension_pulse]
GMN：土地が2,500万円あっても、銀行が貸さないことがある。なぜか。
字幕：土地があっても、銀行は貸さないことがある。

映像：[graphic:flow] 社会保険料滞納 → 督促 → 滞納処分 → 差押え・換価 → 資金繰り悪化 [bgm:tension_pulse]
テキスト：出典：日本年金機構「保険料徴収の取り組み」
GMN：社会保険料を納められないと、督促が来る。指定期限までに完納できなければ、滞納処分へ進む。必要に応じて、差押えや換価が行われる。
字幕：督促の先に、滞納処分がある。

映像：[motoko:explain_right] [bgm:tension_pulse]
少佐：銀行は、担保だけを見て貸すわけではない。返済原資、資金繰り、納税状況、口座の安定性を見る。差押えリスクが見えれば、融資判断は一気に厳しくなる。担保があっても、返済能力が崩れれば貸せない。
字幕：担保より、返済原資と資金繰りを見る。

映像：[graphic:bar_chart] 2023年度末：滞納事業所14万2119 / 差押執行4万2072事業所 [bgm:tension_pulse]
テキスト：出典：帝国データバンク「公租公課滞納」倒産動向調査（2024年度）
GMN：2023年度末、社会保険料の滞納事業所は14万2119。差押執行事業所は4万2072。これは、現場の信用創造を止める数字だ。
字幕：差押えは、信用創造を止める。

映像：[motoko:explain_right] [bgm:tension_pulse]
少佐：税と社会保険を取るために、融資を止め、雇用を壊し、取引先まで巻き込む。これが全体不適応だ。だから設計が必要になる。差押え前に通知し、雇用影響を評価し、再生可能性を見ろ。
字幕：殺して取るな。生かして納めさせろ。

映像：[motoko:fullscreen] [bgm:off]
少佐：設計の欠陥を知れ。設計図を持て。登録して、接続を維持しなさい。
字幕：登録して、接続を維持せよ。

映像：[graphic:dark_text] [bgm:off]
```
