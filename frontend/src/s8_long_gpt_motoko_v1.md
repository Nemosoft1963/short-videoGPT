# 0. オープニング設計

## この長尺版の基本思想

この動画は、最初から数字をぶつけない。  
まず、視聴者に「消費税の影響が消えた世界」を見せる。  

ただし、ここで言う「消費税の影響が消えた世界」とは、単なる夢物語ではない。  
人件費に重くのしかかる消費税・社会保険料の構造負担を軽くし、財源を過剰な蓄積から循環へ移すことで、現場の資金繰り、賃金、投資、信用創造が動き出す世界である。  

視聴者に最初に植え付ける世界観は、これ。  

> 税は、会社を殺すためにあるのではない。  
> 生かして、働かせて、納めさせるためにある。  
> 国は、現場を潰して取るのではなく、現場を生かして循環させるべきだ。

# 15. 制作メモ

## トーン
- 少佐は断定的。ただし、内部留保＝現金という誤解は避ける。
- GPTは視聴者の疑問、反論、恐れを代弁する。
- 冒頭の物語は希望を見せるが、甘くしすぎない。現場のリアルを残す。

## 理論用語の扱い
- TCZ → 国のクセ / 認知の安定領域
- Shared-TCZ → みんなで信じてしまった常識
- LUB → 対立を包み込む上位の答え
- 超情報場・波束収縮 → 長尺本編では直接語りすぎない。代わりに「選べる現実」「見えない未来は選べない」と表現する。

## 反論対策
- 内部留保は現金ではない、と必ず明言する。
- 3%、0.49%、0.95%は制度設計の入口として扱い、固定結論にしない。
- 大企業批判に見せず、資金循環の誘導として語る。
- 裏打ち資料編を別途出す前提を説明欄に入れる。
