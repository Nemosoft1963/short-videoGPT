## 【第三章｜悪法に、どう向き合うか】

映像：[graphic:title] 第三章：悪法に、どう向き合うか [bgm:serious_doc]
テキスト：3つの原則

映像：[graphic:dark_text] 問題は / 悪法をどう壊すかではない / どう設計し直すかだ [bgm:serious_doc]
GPT：消費税は、S1からS8で見たとおり欠陥を抱えた制度だ。悪法と呼んでもいい。だが問題は、悪法をどう壊すかではない。どう設計し直すかだ。どんな悪法であっても、次の三つの原則のもとで制度を改変しなければならない。
字幕：悪法は、壊すのではなく、設計し直す。

映像：[graphic:flow] 原則1:政策コスト最小化 → 原則2:リスクのバランス → 原則3:悪人を作らない [bgm:serious_doc]
GPT：三原則を順に見ていく。
字幕：制度改変の三原則。

### 原則①

映像：[graphic:dark_text] 原則① / 政策コストを / 最小化する [bgm:serious_doc]
GPT：第一。政策コストを最小化する。全面廃止は最大の政策コストを要求する。23兆円の置換、経済への激震、移行の混乱。コストを最小化するとは、動かせる部分から確実に動かすことだ。
字幕：動かせる部分から、確実に動かす。

映像：[graphic:bar_chart] 案1:会社負担社保を控除 / 控除額:約2.7兆円 / 財源:内部留保0.49%課税で補填可能 [bgm:tension_pulse]
テキスト：出典：財務省「法人企業統計調査」2023年度 ／ 詳細はS7
YT：S7で示した案1がその典型だ。会社負担の社会保険料を控除対象にする。控除額は約2.7兆円。財源は555兆円ある内部留保への0.49%課税で補填できる。明日からでも着手できる。
字幕：案1は△2.7兆円。内部留保0.49%で補填、即着手できる。

映像：[motoko:explain_right] [bgm:serious_doc]
少佐：明日から動かせる案がある。それを動かさず「廃止」だけ叫ぶのは、設計じゃないわ。
字幕：動かせる案を放置して、廃止だけ叫ぶな。

### 原則②

映像：[graphic:dark_text] 原則② / リスクの / バランスを取る [bgm:serious_doc]
GPT：第二。リスクのバランスを取る。一つの変数を極端に動かせば、必ずどこかにしわ寄せが出る。財政、雇用、物価、企業の存続。制度改変とは、これらのリスクを一方に押し付けず、分散させながら移行することだ。
字幕：リスクを一方に押し付けず、分散させて移行する。

映像：[graphic:flow] 一つの変数を極端に動かす → 財政・雇用・物価・存続にしわ寄せ [bgm:tension_pulse]
GPT：廃止という単一の操作は、この分散を放棄している。しわ寄せがどこへ行くかを設計しないまま、レバーを引けと言っているに等しい。
字幕：しわ寄せの行き先を設計しないまま、レバーを引くな。

### 原則③

映像：[graphic:dark_text] 原則③ / 悪人を / 作らない [bgm:tension_pulse]
GPT：第三。これが最も重要だ。廃止論はしばしば、政府が悪い、財務省が悪い、大企業が悪いという悪人探しに帰結する。だが悪人を作った瞬間、議論は設計から遠ざかり、対立の演出に堕ちる。
字幕：悪人を作った瞬間、議論は設計から遠ざかる。

映像：A spotlight searching a dark room for a culprit, finding only tangled wiring inside the walls. Cinematic documentary style. 16:9 horizontal. No readable text. Dark muted tones. [bgm:tension_pulse]
GPT：悪いのは人ではない。悪いのは構造だ。構造を直せば、誰も悪人にせずに、全員の負担を軽くできる。
字幕：悪いのは人じゃない。悪いのは構造だ。

映像：[motoko:explain_right] [bgm:serious_doc]
少佐：政策コストを最小化し、リスクを分散し、悪人を作らない。この三つを外したら、それはもう設計じゃない。ただの破壊よ。
字幕：三原則を外せば、それは設計ではなく破壊だ。
